Why this takes months

Money can't drift

Balances have to reconcile to the last unit, forever. That means integer arithmetic, append-only ledgers, and row locks — not a balance column you increment.

Two wallets, one transaction

A sale debits a buyer, credits a seller and credits you, atomically. Get the lock order wrong and you deadlock under concurrency instead of at your desk.

Webhooks decide the truth

The gateway confirms payment out-of-band, retries, and replays. Every capture path has to be idempotent and every signature check has to fail closed.

What "correct" means here

One invariant, always true

A user's balance equals the sum of their ledger rows. The cached column is a read optimisation; the ledger is the truth. The demo seeder asserts this and refuses to finish if it fails.

Integers, never floats

Every amount is an integer in the currency's minor unit. A fee split adds back to the price exactly — no cent drifts away at volume. INR, USD, JPY and KWD all render correctly.

Fails closed by default

An unconfigured webhook secret rejects every request instead of accepting unsigned ones. Stripe webhooks are replay-checked against a timestamp window.

Swap the gateway, not the app

Razorpay and Stripe both implement one interface. Adding a third is one file and five methods — nothing that touches money changes.

// One sale. Buyer debited before seller is credited —
// a single fixed lock order prevents deadlocks.
db.Transaction(func(tx *gorm.DB) error {
  fee, net := wallet.SplitFee(price, feePct)   // 9990, 89910

  wallet.Apply(tx, buyerID,  PurchaseDebit, -price, ...)
  wallet.Apply(tx, sellerID, SaleCredit,    +net,   ...)
  platform.Apply(tx, PlatformFee,           +fee,   ...)

  return nil
})

// Rolls back as one unit. No half-finished sale,
// no credit without a matching debit.

What it doesn't do

Worth knowing before you buy:

  • Payouts record intent and capture bank/UPI details — actually sending money is manual or your own integration, because payout APIs are country-specific.
  • One currency per deployment. Amounts are stored in that currency's minor unit and are not converted.
  • Push notifications need your own Firebase project. Everything else runs without it.
  • You bring your own gateway account, SMTP provider and server.
